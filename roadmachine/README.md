# roadmachine

Gear shortlist for the BMC Roadmachine X TWO — helmets, SPD shoes, accessories,
and color-matched picks. Single static HTML file, no build step.

- **URL**: https://roadmachine.93.fyi
- **Source**: `index.html` (self-contained: inline CSS + Google Fonts)

## Deploy

Vercel auto-deploys this directory on push to `main`. Pure static — no build
command, output dir is `.`.

## Edit

Just edit `index.html`. Cards/grids are plain HTML; the lime/black palette is
defined in CSS custom properties at the top of the `<style>` block.
